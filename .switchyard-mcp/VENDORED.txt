Switchyard MCP servers, copied into this project so sessions that cannot reach your own machine
(a cloud session, another clone) can start them. They are started by .mcp.json in the project root.

Version: 1.24.0
Update or remove: run `./switchyard.sh clients vendor --into <this project>` (add --remove to
take them out) from a Switchyard checkout. Do not edit these files here: an update replaces them.

Without SWITCHYARD_URL in the session's environment the tools work locally and report nothing.
